Cloud Infrastructure Performance & Cost Optimization Dashboard

Microsoft Excel Power Query Power Pivot Pivot Tables Dashboard Design Data Analysis

Cloud Infrastructure Performance & Cost Optimization Dashboard built in Microsoft Excel to analyze cloud costs, resource utilization, infrastructure performance, and optimization opportunities. Features interactive dashboards, KPIs, charts, slicers, and actionable insights across cloud providers, regions, and VM types.

Organizations using cloud services often struggle to balance infrastructure performance with operational costs. Without centralized reporting, it becomes difficult to identify inefficient resource utilization, compare cloud providers, monitor infrastructure health, and prioritize cost optimization efforts.

This project addresses these challenges by transforming cloud infrastructure data into an interactive Excel dashboard that provides meaningful insights into performance, utilization, and cost efficiency.
  • GCP recorded the highest monthly cloud cost at 5,964.77, followed by AWS (5,803.56) and Azure (5,473.08), indicating higher infrastructure expenditure on GCP.
  • AWS delivered the highest average throughput of 1,117.65, outperforming GCP (1,072.68) and Azure (1,063.06), suggesting better workload processing efficiency.
  • The n1-standard-1 VM type had the highest average resource cost (34.20), whereas B1s (8.64) and t2.micro (8.35) were considerably more cost-efficient.
  • AWS was identified as the most cost-efficient cloud provider, while US-WEST emerged as the lowest-cost region, making them strong candidates for cost optimization strategies.
  • A total of 75 resources were classified as High Priority, highlighting infrastructure components that require immediate optimization or monitoring.
